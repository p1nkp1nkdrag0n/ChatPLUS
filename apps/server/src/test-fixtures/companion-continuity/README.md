# 合成连续性测试输入

本目录包含人工编写的固定角色、120 轮用户场景及评审标准，供连续性实验 CLI 在干净检出中运行。人物、关系、编号和事实均为合成测试输入，不是用户聊天、运行数据库或模型测试结果。

- `03_scenario.public.json`：按顺序提供当前用户消息。执行器不能把未来剧本提供给角色模型。
- `04_oracle.private.json`：事实与作用域评审标准。`private` 表示仅供评审、不得进入角色或模拟用户提示词；不是个人私密信息或访问凭据。其 `publicScenarioSha256` 绑定场景原始字节。
- `build_scenarios.py`：离线生成上述两份输入的来源脚本，不调用模型或网络。修改场景时应在隔离副本中生成，并一并更新场景和 oracle。

保留 JSON 原始字节；不要只格式化其中一份输入。CLI 默认从本目录读取，仍可用 `--public` 和 `--oracle` 指定另一组匹配输入。运行结果、请求记录、数据库、评分与报告写入忽略的 `tmp/` 或 `artifacts/`，不加入源码仓库。
