# 记忆档案室贴图

这三张贴图使用内置 `imagegen` 生成。柜体背板的风格参照为 Dearvale 官网素材 [`desk.png`](../desk.png) 与 [`botanical.png`](../botanical.png)。本目录的 PNG 是生成原图，予以保留；同名 WebP 是供网页加载的导出版本。

完整生成提示词与参考图映射见 [`prompts.json`](./prompts.json)。书柜植物作为场景边饰，书封布纹按角色颜色叠色，纸纹仅作阅读底色。木搁板复用布纹进行横向缩放和色彩混合，未增加额外图片请求。

| 文件名（省略扩展名）   | 用途                         | WebP 尺寸   | WebP 大小    |
| ---------------------- | ---------------------------- | ----------- | ------------ |
| `cabinet-botanical-v1` | 档案室柜体背板与植物装饰背景 | 1536 × 1024 | 211,162 字节 |
| `bookcloth-v1`         | 月度书卷封面、书脊的布面质感 | 768 × 768   | 205,748 字节 |
| `diary-paper-v1`       | 翻页阅读器内页的纸张底纹     | 768 × 768   | 43,632 字节  |

WebP 由 bundled Sharp 以质量 `85` 导出。背板保持原尺寸；布面与纸张从 1254 × 1254 等比例缩小到 768 × 768。转换仅涉及尺寸与编码，未裁剪、重绘或修改图案。重新导出时应保持上述尺寸与编码参数。

这些素材只用于装饰层，不得侵入日记正文布局：标题、日期、正文、控件和分页均由真实界面元素承担；贴图不决定正文尺寸或页数，图案不得遮挡文字、降低阅读对比度或覆盖交互区域。书卷封面和书脊使用布面贴图，日记阅读区域使用低干扰纸纹，背板植物保留在装饰背景中。
