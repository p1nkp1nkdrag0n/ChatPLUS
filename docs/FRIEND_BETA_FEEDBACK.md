# Dearvale 内测反馈与覆盖记录

这是空白模板。每位朋友复制一份，只填写实际做过的内容；不要把未触发或未执行写成通过。

仓库只公开空白模板。填写后的反馈、参与者对应表、截图与原始聊天材料保存在本地 `artifacts/friend-beta/` 或 `docs/reports/`，不要回填到本文件后提交。

### 3. 不看标准答案的感觉

1. 最困惑或最想退出的一步：
2. 最像这个角色的一次回应；最出戏的一次回应：
3. 只能先改一件事，我会选：

5. 有没有因为跟着指引，没能试到自己真正想做的事情：

可选评分（没体验写“不适用”）：

| 项目       | 1 分 → 5 分                          | 我的分数与原因 |
| ---------- | ------------------------------------ | -------------- |
| 找到下一步 | 完全不知道 → 很容易                  |                |

| 问题编号 | 类别                            | 影响 | 关联角色/会话/调用线索 | 是否复现 | 后续处理 |
| -------- | ------------------------------- | ---- | ---------------------- | -------- | -------- |
|          | 阻塞 / 结果错误 / 体验 / 未覆盖 |      |                        |          |          |

“没收到主动消息”“没出纪念物”等，先查开关、资格、实际来源、时间窗口与任务结果；仍不确定就保持待核对。不要强行归为用户不会用，也不要在没有证据时直接归为模型错误。

- 主线实际耗时；最长的三个等待：
