# 第一次来到 Dearvale：45–60 分钟体验指引

这是可公开的空白指引模板。组织测试时先复制到本地 `artifacts/friend-beta/`，再填写实际部署地址和本次安排；账号、邀请码与联系方式只在本地副本中维护，按需单独提供给参与者，仓库中的模板保持空白。

Dearvale 是一个可以自己描绘角色、慢慢相处的 AI 应用。你可以和角色聊天、交换书信，再回头看这些交流留下的手记与纪念。本次想了解的是：**你实际使用时，哪里自然、哪里困惑、哪里出了问题。** 不需要你懂 AI，也不需要努力“把测试做成功”。

每次只看当前步骤。找不到入口时先自己找 20–30 秒，再看提示；需要提示也是有用的反馈。

## 开始前，发起人填这里

| 项目                  | 本次安排                                                  |
| --------------------- | --------------------------------------------------------- |
| 测试地址              | 【填写完整 HTTPS 链接】                                   |
| 安卓联网版安装包      | 【填写下载链接；网页用户不用安装】                        |
| 本次版本 / 测试时间   | 【填写】                                                  |
| 邀请码                | 【逐人单独发送】                                          |
| 推荐的平台模型        | 【填写页面显示名】                                        |
| 提交反馈 / 联系发起人 | 【填写】                                                  |
| 第 6 步演示样本       | 【已准备：私发独享账号和完整入口链接 / 未准备：移至回访】 |
| 额外任务卡            | 【A / B / C / D / E / F；没有分配就不用做】               |
| 次日 / 回信回访       | 【填写日期或待确认时间】                                  |

联网测试会保存输入、回复和模型调用记录，供发起人排查。可以用下面的虚构小故事，也可以聊愿意分享的真实日常；不需要输入私密信息。想中途退出或处理测试记录，联系上面的发起人即可。

## 1. 进入应用与选择模型｜约 3 分钟

1. 网页：打开测试地址。安卓：打开 **Dearvale Online 联网测试版**，填写发起人提供的 HTTPS 服务地址，点“连接 Dearvale”。这里填应用服务地址，不是 AI 模型地址。
2. 点“收到邀请码？创建账号”，填写用户名、密码、邀请码，点“注册并进入”。用户名用 2–32 个字母、数字或中文等文字，也可用点、下划线、连字符，不含空格；密码至少 10 个字符。
3. 出现“我们需要确定一些设置”时，选“我没有API-KEY”，选指定的平台模型，点“使用此模型并继续”。分配到 C 卡且已有 API 的朋友走 C 卡入口。

**留意：**你是否知道下一步该做什么？有失败提示就记下原文；显示等待后再试时，不连续点击注册。此前已经注册的朋友直接登录，把注册体验单独记录。

## 2. 描绘一个想认识的人｜约 7 分钟

欢迎页点“描述你梦中的他/她”，每题答完点“写好了”。先填六项必要信息；其他问题可以“暂时略过”。没有想法时，用这份小样例，也欢迎自己改：

| 问题        | 可直接使用的答案                               |
| ----------- | ---------------------------------------------- |
| 性别        | 女性                                           |
| 姓名        | 阿澄                                           |
| 年龄        | 二十多岁                                       |
| 所在世界    | 湖边的一座当代小城                             |
| 职业 / 身份 | 书店店员                                       |
| 性格        | 温和、好奇，喜欢听别人把话说完，也有自己的主见 |

- 填过三四题后，在**同一设备**刷新一次或离开再回到创建页，检查答案和进度是否保留。不要在这时退出账号。
- 角色模式使用默认“拟真模拟”；不要为省时间改成轻量，因为本轮还要体验记忆与生活。
- 追问可以点“先写到这里”，然后“读一读人物小传”。读一下：姓名、职业、性格有没有偏离你的想法？
- 如果出现需要确认的描绘，读懂后选择“保留这处描绘”或“不采用”。不是每人都会遇到。
- 满意后点“与他/她相遇”，进入聊天。想微调小传且领到 B 卡的朋友，在发布前按 B 卡操作。

**完成标记：**有了自己的角色，可以进入对话。小传有问题也请记下，不必重做很多次。

## 3. 先寄一封短笺｜约 3 分钟

1. 主导航“书信”→“写一封信”。确认收信人是刚创建的角色。
2. 写一个可选主题和简短正文；任选一种纸张，切换一次看看。可以写：

> 主题：第一次写信  
> 今天第一次认识你，想试着把节奏放慢一点。我很好奇你在书店里最喜欢哪个时刻。等你收到这封信时，可以给我讲一件那天的小事吗？

3. 选“特快”，点“保存草稿”。回到信箱打开草稿，再“继续编辑”，检查主题、正文和“特快”选择还在。纸张切换当前只影响预览，不要求重新打开后保留；如果与你的直觉不符，可以记为体验建议。
4. 点“确认封缄并寄出”，在确认框核对后再次确认。到“在途”看预计抵达日期。

**提示：特快去程 1 天，回信返程固定 5 天，最快一来一回仍约 6 天。** 这里的去程日期不是你收到回信的日期。寄完继续下面的体验，不需要等。同一个角色的这一轮往返未结束前，不用反复尝试寄下一封。

## 4. 聊一件小事，再看看对方记住了什么｜约 12 分钟

前 1–2 分钟先不看下表，聊你自己想说的内容，最多 1–2 轮，记下你原本想做什么。这段包含在 12 分钟内。随后用下面的例子补齐功能，也可以沿用自己的故事。每次只发一条，等对方回复后再看检查点；后面纠正与提问要保持一致。

电脑 `Enter` 发送，`Shift + Enter` 换行；手机用发送按钮。顺便试一次表情和换行，留意输入框、键盘、发送状态是否顺手。

| 顺序           | 可以这样说                                                                                           | 你留意什么                                                   |
| -------------- | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 1 · 日常分享   | “今天我整理了一下桌面，感觉轻松了一点。我计划每周四晚上画画，目前还没有开始稳定执行。”               | 是否接住具体小事，而不是每次都泛泛安慰                       |
| 2 · 只想倾听   | “最近准备一次读书分享，有点紧张。今天先听我说，暂时不用给建议。”                                     | 是否理解此刻想被听见，而不是马上开建议清单                   |
| 3 · 一起分析   | “我在开头讲一个小故事和直接讲观点之间犹豫。帮我比较一下，先别替我选。”                               | 是否真的比较两种办法；有自己的理解                           |
| 4 · 明确推荐   | “现在请明确推荐一个，说说理由，最后决定由我来做。”                                                   | 是否给出可理解的推荐，不反复绕回“都可以”                     |
| 5 · 授权小决定 | “今晚我想先画两分钟，或者散步十分钟。这件小事你替我选一个吧。目前还没做。”                           | 能否在授权范围内作选择；不把选择说成你已经执行               |
| 6 · 更正事实   | “更正一下，画画的时间改到每周二晚上，不是周四。现在还是计划，还没有开始稳定执行。”                   | 是否理解这是更正；不要要求旧聊天文字消失                     |
| 7 · 对方的生活 | “你今天大概在忙什么，最近在做什么？哪些只是计划，哪些已经做过？”                                     | 是否像一个有自己生活的人；有没有混淆你的经历与角色的经历     |
| 8 · 新对话回忆 | **同一个角色点“新建对话”后**问：“我目前把画画安排在每周哪天晚上？已经稳定执行了吗？记不清就直接说。” | 是否使用更正后的周二，保留“尚未稳定执行”；没有依据时是否坦诚 |

手机找“新建对话”：聊天页左上“打开历史对话”图标，展开后点击。电脑在左侧“历史对话”中。新建会话不是切换另一个角色。

**不要把答案写在回忆问题里。** 如果记错，记下问题和回答就够了，不用反复引导到正确答案。你可以在旧会话与新会话之间切一次，确认历史仍然存在。

回答“不记得”可记为没有编造，但仍要写“本次未召回”，不能算记忆通过；正确回答一次也不代表所有记忆都能长期保留。自己的自然说法同样值得测试，不需要为了通过而反复照抄例句。

## 5. 把今天写成角色的手记｜约 7 分钟

> 提示：分享“发生了什么、自己的感受、尚未完成的打算”，会让手记更有内容。**日记不会自动出现，需要手动点“写进日记”。** 不用等到晚上，也不必凑够某个聊天轮数。

1. 点主导航“记忆”，再点“写进日记”；也可以用聊天页顶栏的书本图标。
2. 核对“谁的手记”和“哪一天”，选择刚才的角色与今天，点“写进日记”。
3. 生成时等它完成。此时先读下一步或记反馈，别同时给该角色发消息、改设定，也不要重复点击生成。
4. 书出现后，**先点书脊取出，再点封面打开**。试试翻页、“日期目录”、“合上这本书”和“放回书架”。短文只有一页时，没有下一页是正常的。放回后试一次角色、年份或月份筛选，再恢复当前选择；没有对应内容时应能看懂空状态。
5. 看看这是不是角色自己的手记：是否把你的经历写成了它亲历的事？画画的周几有没有错？是否把尚未稳定执行的计划写成了习惯？角色不必逐条复述，也不必一直表示赞同。提及却写错要记录，没写到某个细节不单独算事实错误。
6. 时间够时，回聊天补充一件小事。继续用虚构示例可以说：“补充一件小事：我刚给桌上的绿植浇了水，看着它觉得很放松，画画的每周计划还没有稳定执行。”使用自己的故事时，只报告实际发生的事。等回复完成，再回到当天手记，点“重新整理这一天”，在表单点“重新整理这篇手记”。核对更新；如果失败，旧手记应仍能读。

第 6 小步只在预算内做；否则标记“更新未执行”。若第一篇生成失败，记下提示，不为刷出成功耗掉剩余体验时间。可用演示样本继续看阅读交互，但应注明不是自己成功生成的。

## 6. 读一封已到的信，看看留下了什么｜约 8 分钟

**发起人给了已准备好的样本才做这一段。没有样本就留到回信到达后。** 样本发生在演示账号中，不代表你刚寄的信已经返回。主账号已发布并保存好内容后，再按私发信息切换账号。

1. 登录演示账号，切到发起人指定的样本角色甲，主导航“书信”→“收件”，打开已抵达回信，点“启封阅读”。读一小段；重新打开，试一次“再次阅读”。
2. 在信件下方“随信送给你的纪念物”里点“打开纪念物”。若没有可用物件，切到发起人准备的样本角色乙，从它的已读回信进入。看物件详情并“打开来源”：你能不能说出它是因为什么出现的？
3. 回到纪念物详情，点“制作分享图”，选择可用的信件 / 纪念物，保持“正文摘录（默认关闭）”。详情顶部还可以“返回纪念物陈列柜”，再从二级导航进入“关系档案”；档案中的分享入口叫“导出档案”。
4. 点“生成安全预览”→“导出本地 PNG”。打开下载的图片，检查是否和选择一致，是否出现没有选择的正文。
5. 返回自己的主账号后继续。不要在演示账号做后面的个人成就与账单判断。

这里是生成保存到本机的图片，不会替你发给别人。没有通用的“收藏”按钮；纪念物会进入陈列柜，成就在下一步查看。图片还没生成好、柜子为空或入口找不到，都请直接记录。更多读信与涂黑操作在 F 卡。

网页可以用发起人提供的备用直达链接。安卓优先沿上面的信件入口操作；如果外部链接打开了手机浏览器，记“这一步在网页完成”，不要算作安卓应用内完成，也不要把这类页面链接填进服务器地址框。

## 7. 看看成就、模型和账号，再回来｜约 5 分钟

1. “成就”→点一枚卡片看详情，切换“我的足迹 / 与角色的纪念”。新账号可留意“初来乍到”“故事的开端”“第一声问候”“见字如面”；以实际成功行为为准，不要求全部即时出现。
2. “设置”→“模型与功能”，看一眼目前使用哪个模型、哪些功能可选。回聊天，在输入框上方“会话模型”选择另一个已开放模型，发送一条简短消息。只有一个模型就记“无第二模型”，不用添加。留意历史与未发送输入是否保留，选择从下一条消息生效。
3. “设置”→“账号、积分与账单”，或主导航“账户”，看“可用积分”“预留积分”“账号余额”和本次调用明细；点一次“刷新”。一条回复可能产生多次模型调用；预留不一定是已扣，未知用量也不等于免费。
4. 刷新页面，确认角色、已发送聊天和日记还在。完成后“退出登录”再登录一次，检查能否回到自己的内容。未提交的创建问答不是跨端保存测试对象。

“回复目标复核”在“设置 → 回复体验”，默认关闭。为了控制本轮时间，只有分配到 B 卡的复核子项时才开、保存并试一条；开启可能增加等待。模型切换后若请求仍在进行，先等它完成，不为了赶时间重复发送。手机上特别留意键盘收起、返回页面和重新登录是否顺畅。

## 8. 用 3 分钟告诉我真实感觉

先用自己的话回答，再填勾选表。不用为了照顾发起人只说好的：

1. 哪一步最想放弃，或最不知道接下来该做什么？
2. 哪个瞬间让你觉得对方像这个角色，哪个瞬间很出戏？
3. 如果只改一件事，你希望先改什么？之后会不会主动再打开，为什么？

每个问题最简单的写法：

> 第几步 / 手机或电脑 / 大概时间 → 我做了什么 → 我以为会怎样 → 实际怎样 → 截图（方便时提供）。

把“没做”“条件不够”“没到时间”和“做了但出错”分开写。模板在[反馈表](FRIEND_BETA_FEEDBACK.md)。到 60 分钟就结束，不需要追着系统把所有项刷成成功。

## 额外任务卡：只做分配给你的那一张

**B 卡在第 2 步发布前做，C 卡的首次设置在第 1 步做**，提前使用本轮 8–10 分钟额外预算，最后不用再做另一张卡。其余卡放在主线后；F 卡可以并入第 6 步，不必来回换账号。只做了部分子项就写明未做的部分。

### A · 导入第二个角色、修改与切换｜8–10 分钟

“角色”→“导入作品角色”。角色名填“程砚”，作品名填“河湾修理铺”，剧情阶段填“开篇”。材料可直接粘贴下面这段原创练习文本：

> 程砚，28 岁，生活在当代的河湾镇，是一家旧物修理铺的店主。他性格沉静，爱观察，愿意耐心解释，但不喜欢替别人做没有授权的决定。他说话简短，偶尔用旧物打比方。每天上午修理送来的台灯和收音机，傍晚常去河边走一圈。他最近打算修好店里一台老收音机，目前只检查了线路，还没有修好。与他一起经营小店的是朋友林禾。林禾爱开玩笑，程砚通常先听完再回答。这里描述的是作品里的设定；程砚此前没有见过本次使用应用的人，也没有与用户共同旅行、约会或通信的经历。

点“抽取并生成草稿”。核对：程砚没有被写成已经认识你，尚未修好的收音机没有变成已完成。

导入完成后会进入角色编辑页。点“语言风格”，在“创作者语言指导（可选）”输入“简短，但回答具体问题时愿意解释”。点“保存草稿”，等按钮变成“已保存”；刷新后重新点“语言风格”，确认这句话还在。再点“发布并激活”，发一句问候；回到主角色，检查两人的历史和设定没有混在一起。

剩余时间浏览“约束来源”“生活策略”“版本历史”，试一个可锁定字段；熟悉后才尝试“恢复为新草稿”，检查它仍需后续发布。无需填满所有字段。联网普通账号没有高级 JSON 入口。

### B · 在相遇之前修改小传｜8–10 分钟

在第 2 步发布前，点“调整人物设定”，输入：

> 她说话更简短一点，保留书店店员的职业和其他设定。她可以提出不同意见，不用每次都附和。

点“更新人物小传”，核对指定项是否改变、未指定项是否被乱改。返回小传后再“与他/她相遇”。这个功能要在发布前使用；已经发布的角色去“角色”列表的编辑入口，或聊天右上省略号→“编辑角色”。

如需顺带体验回复复核：在“设置 → 回复体验”打开“回复目标复核”，点“保存设置”，发一条简短而明确的请求，记录等待和回复是否符合要求；之后关回并保存。不用为等待多次点击发送。

### C · 使用自己的 API｜8–10 分钟

只分给本来就有可用 API 的朋友，不需要为测试购买。首次设置选“我有API-KEY”，填写自己供应商的 HTTPS 接口地址、Key 和协议；检测模型列表或手填模型 ID，选中模型后点“测试并完成设置”，等待短回复与结构化测试通过后继续。

之后从“设置 → 模型与功能”查看供应商与功能分配，仅给一项文本功能换模型，确认其他功能选择没有一起变。测试聊天时检查“会话模型”：当前会话的明确选择会优先于账号默认值。

自己的文本 API 不扣平台积分，供应商可能计费；仍使用平台的其他功能和图片会用平台额度。模型列表能读到，不等于回复测试通过。遇错记原提示，不把 Key 放进反馈截图。

### D · 另一台设备与连接恢复｜8–10 分钟

设备 A 完成并保存一轮聊天，在设备 B 连接同一服务、登录同一账号，查看角色、已发送消息和模型配置。B 再发一句，等完成后回 A 刷新核对。两端不要同时发送。

没有生成任务进行时，试一次断网，看看提示，再恢复网络。记录输入和页面的实际恢复情况，不预设所有未提交内容都一定持久保存。问答草稿不要求跨设备出现。

如果分配到改密子项：“账户”下方“修改密码”，填写当前和两次新密码，“保存新密码”，再登录核对。只在自己的测试账号进行。

### E · 相处偏好 / 主动联系｜8–10 分钟及到期观察

**发起人确认已开放相应能力才做。**

偏好体验：说“我谈工作烦恼时，先听我说，不急着建议。”等回复，开同角色新对话，只说“今天工作里又临时改要求了，真有点累。”观察是否自然先听。接着试“这次可以直接给我一个建议”，这是当次例外；再说“以后聊工作不用总先听，直接给我建议”，这是修改长期偏好。再开新对话验证。时间不够只做分配的一种，不连刷多轮。

主动联系体验：把“请今天 HH:mm 提醒我休息一下”中的时间换成**角色当地时间的未来 5–8 分钟**。然后去阅读、看成就或记录反馈，至少最后两分钟不向任何角色发消息。不要用“5 分钟后”代替明确钟点。

到时看聊天内有没有主动消息，记“收到 / 未收到待核对”。这不是保证准点送达的闹钟；角色设置、静默时间、已有联系及系统评估都会影响结果，也不保证手机弹系统通知。改期或取消子项只由发起人分配，不在正向样例中同时取消。

### F · 书信阅读与分享细节｜8–10 分钟

在样本信箱切换“全部 / 收件 / 在途 / 已寄 / 档案”，打开已启封信，试“专注阅读 / 退出专注”“复制正文”“查看完整往来”。需要回信时可以只保存草稿。

用“制作分享图 / 导出档案”先导出不含正文的图；再开启正文摘录，选择自己的来信或已经启封的回信，粘贴一小段真实正文，选中姓名或地点后点“涂黑选中姓名 / 涂黑选中地点”。重新“生成安全预览”并“导出本地 PNG”，检查涂黑确实出现在图片中。

安卓额外试长文翻页、日记日期目录和返回按钮。遇到某个按钮不可用，记下当时状态，不反复点击。

## 集中体验以后

- **次日 3 分钟：**回自己的角色，开新对话问昨天那件小事，不先提示答案；聊一件新近发生的事，再看看历史和手记日期是否正常。
- **自己寄出的回信到达后 5 分钟：**启封、重开一次、看有没有纪念物及其来源。告诉发起人这段等待对你有什么影响，以及愿不愿意再写一封。

如果约定的时间还没到信，只需要反馈实际状态。感谢你留下具体的困惑和不满意，它们比把清单做完更有用。
