# Dearvale 安卓版连接电脑或服务器

安卓版内置手机前端，角色、聊天、模型配置和后台任务仍由电脑或服务器上的 Dearvale 服务处理。首次打开 APK 时填写服务器地址、用户名和连接密码；更换电脑、Wi-Fi 或服务重启后，可在应用的连接设置更新。

## 在同一 Wi-Fi 下连接电脑

电脑需已安装 Node.js 22.12–24 和项目指定版本的 pnpm，并已在仓库根目录执行 `pnpm install`。在仓库根目录运行：

```powershell
pnpm mobile:serve
```

该命令构建前端、启动后台，并输出类似以下连接信息：

```text
服务器地址：http://192.168.1.18:3000
用户名：mobile
连接密码：<本次运行生成的随机密码>
```

将实际输出的三项填入 APK。服务器地址只填写 `http://IP:端口`，不要添加 `/api`、页面路径或用户名密码。电脑与手机连接同一可信 Wi-Fi；在 APK 中确认局域网 HTTP 使用提示。HTTP 不加密，同一网络中的攻击者可能读取流量和连接密码，因此这个入口仅适合可信家庭网络，不应用于公共 Wi-Fi、公网端口映射或直接发布互联网服务。

连接密码每次运行随机生成，仅保留在服务内存和当前运行窗口中，不写入 `.env`、仓库或数据库。重启服务后在 APK 中输入新密码。请保持运行窗口开启、电脑保持唤醒；按 `Ctrl+C` 同时关闭局域网入口和后台。

脚本读取现有项目 `.env` 的模型与数据设置，使用现有电脑实例。首次使用可在应用里完成角色和模型设置；已有实例继续使用同一数据库与资产目录。不要同时对同一个数据库启动多个普通开发、桌面或手机后台实例。

## 网络选择与排查

默认选择本机已分配的私有 IPv4 地址，并优先普通网卡。多网卡电脑可显式选择手机能够访问的地址：

```powershell
pnpm mobile:serve --host 192.168.1.18 --port 3000
```

- **找不到局域网地址：** 先连接 Wi-Fi 或网线；脚本只接受本机已有的私有 IPv4。VPN 或虚拟网卡地址通常无法从手机访问。
- **电脑防火墙拦截：** 若 Windows 询问 Node.js 的网络权限，允许“专用网络”。不要关闭整个防火墙。确认当前家庭 Wi-Fi 在 Windows 中设为专用网络。
- **手机连接超时：** 检查 IP 是否变化、两端是否同一 Wi-Fi、路由器是否开启访客网络或客户端隔离，以及电脑是否休眠。
- **用户名或密码错误：** 用户名是 `mobile`，密码使用当前运行窗口里的完整内容。服务重启会使旧密码失效。
- **端口占用：** 停止旧的运行窗口，或运行 `pnpm mobile:serve --port 3002` 并在 APK 中填写新端口。
- **仅电脑检查：** `pnpm mobile:serve --host 127.0.0.1`。这个地址只能在电脑上访问，不能填进真实手机。
- **前端已经构建：** 可以使用 `pnpm mobile:serve --skip-build` 缩短启动时间；改过前端后请使用默认命令重新构建。

## 连接长期运行的 HTTPS 服务器

按 [自托管指南](SELF_HOSTING.md) 部署已有的 Docker Compose + Caddy 配置，然后在 APK 中填写 `https://你的域名` 及该实例的 Basic Auth 用户名、密码。使用可信 HTTPS 证书；安卓版不绕过证书校验。

局域网命令用于连接电脑，公网服务器应继续使用已有的 HTTPS 认证反向代理。当前是单用户实例：共享入口和口令意味着共享全部角色、聊天与配置。

## 实现与验证

`scripts/mobile-serve.ts` 保持应用后台监听 `127.0.0.1` 的动态端口，保留既有 `deployment-boundary.ts` 约束。独立入口仅绑定选中的本机私有 IP，不使用 `0.0.0.0`，也不启用 `SELFHOSTED_REVERSE_PROXY`。默认关闭开发专用路由。

`scripts/mobile-gateway.ts` 对网页、API、图片和 SSE 执行同一 Basic Auth 检查，返回标准 `Dearvale` 认证挑战；转发前移除认证头、Cookie 和伪造代理头，校验 Host 与跨站 Origin，直接流式转发聊天事件和上传内容，不记录请求头、正文或口令。启动输出中的随机连接密码与模型 API Key 无关。

运行有实际 HTTP 请求的针对性验证：

```powershell
pnpm exec vitest run apps/server/src/mobile-gateway.test.ts
```

验证覆盖未认证请求、错误密码、跨站写入、凭据不向后台传递、请求正文与参数保留、SSE 首段即时到达和断线清理、后台不可用响应，以及私有地址选择。
