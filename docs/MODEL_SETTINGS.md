# 模型设置与连接验证

单机版在“设置”的供应商列表点击“添加供应商”；联网版从“设置”进入独立的“模型与功能”页面管理个人供应商。填写名称、接口类型、API 地址和密钥。API 地址为接口根路径，常见示例：

| 接口类型           | API 根地址示例                                     |
| ------------------ | -------------------------------------------------- |
| OpenAI 兼容        | `https://api.openai.com/v1`                        |
| Anthropic Messages | `https://api.anthropic.com/v1`                     |
| Gemini             | `https://generativelanguage.googleapis.com/v1beta` |
| 本地 OpenAI 兼容   | `http://127.0.0.1:11434/v1`                        |

聚合网关可以使用自定义路径。无需鉴权的本地服务仅在单机版允许密钥留空；联网版个人供应商需要 API Key，并且只接受公网 HTTPS 地址。已有密钥不回显；编辑时留空保留旧值，输入新值替换，勾选“清除已存密钥”才会清除。更换供应商源站或协议后，需要重新填写密钥，避免将原凭据发送到另一个地址。

点击“检测模型”读取列表，再从下拉框选择模型。若供应商没有列表接口，直接添加模型 ID 也可以使用。列表可搜索，多个模型各自保存高级参数；刷新列表不会覆盖已配置的高级参数。

高级设置默认折叠，包括请求超时、结构化方式、思考设置、输出 token 上限和上下文上限。新模型的上下文预算默认 **64,000 token**，可以逐个修改；默认使用提示词 JSON，思考设置使用模型默认值。不同原生协议仅显示对应的参数；检测列表不等于检测模型所有能力。

供应商列表返回的上下文、独立输入和最大输出限制会作为模型元数据保存，与用户填写的预算分别展示。实际预算受已知供应商限制约束，不能通过增大填写值扩展模型能力；刷新列表保留已有模型的手动参数。聊天上下文组装还应用 258,000 token 的应用总窗口，并为输出与传输保留空间。没有返回限制的模型仍可手填，短回复测试不能验证其最大上下文。

## 联网版首次设置与功能模型

新账号登录后先显示“我们需要确定一些设置”：

- **我没有API-KEY**：选择平台文本模型，保存后进入 Welcome 欢迎页。
- **我有API-KEY**：填写 URL 与 API Key，检测列表或手填模型 ID，在下拉框选定模型并调整参数；点击完成时保存配置并执行短回复、结构化测试，两项通过后进入 Welcome。测试失败可继续修改，不会将首次设置标记为完成。

首次选择会初始化全部文本功能。图片生成仍使用平台图片模型，引导中说明会消耗平台额度。“模型与功能”页面随后可以按聊天、角色编译与访谈、回复复核与改写、记忆整理、生活规划、书信和日记等用途分别选择平台模型或自己的模型，也可以批量应用到全部文本功能。图片有独立选择器，当前仅支持平台图片模型。

聊天优先使用当前会话明确选择的模型，再使用账号的聊天功能设置；未设置的功能采用平台对应用途模型。已配置的个人模型失效、Key 无效或供应商请求失败时会报告错误，不自动改用消耗额度的平台模型。删除供应商或模型前，仍有引用的功能需要先重新选择模型。

个人 API 调用及连接测试不冻结、不扣除平台积分；供应商可能按自己的规则收费。用量缺失时记录为未知，平台积分仍不冻结。平台功能继续按积分规则处理，因此文本使用自己的模型时，图片或单独选择的平台功能仍会消耗额度。自带 Key 沿用现有研究采集流程，不增加许可确认或提醒文案；API Key 与认证头不作为采集字段。

配置、功能选择和首次设置完成状态保存在账号所属的服务端数据库。同一服务器、同一账号在网页与安卓端读取相同设置，客户端不需要重新输入 Key；这不依赖浏览器缓存或设备安装状态。同时编辑时使用配置版本检查，过期提交会要求刷新。升级前已有账号保留原入口与配置，并迁移为已完成首次设置。

## 保存、默认与会话选择

普通供应商管理中的“保存配置”保存供应商、凭据和模型参数，不产生生成请求。联网版首次引导的完成操作会明确执行前述测试。单机版“全局默认模型”用于跟随默认的会话、角色生成与后台模型任务；联网版使用账号的功能模型设置。单机版已有环境变量配置仍可作为只读来源，使用“复制为可编辑配置”交给页面管理；原 `.env` 不会被修改。

对话输入框上方可以跨供应商切换模型，选择只保存到当前会话，从下一条消息开始使用。选择“跟随全局默认”后，该会话继续跟随全局设置。切换不会改变历史消息或清空正在输入的文字。

单机版每一轮生成及自动修复固定使用开始时捕获的配置，两个会话不会串模型。联网版按各功能选择模型，同一次操作已捕获的功能配置不随之后的设置修改而改变。删除供应商后，引用它的会话会显示失效并要求重新选择；应用不会默默改用另一家供应商。删除全局默认供应商或其默认模型前，请先更换默认选择。

## 如何判断模型可用

“测试连接与回复”针对当前模型最多发送两次真实短请求：先确认能返回非空、可见的简短文字，再要求返回包含非空 `reply` 的 JSON，使用实际生产适配器解析并校验。

- **绿色**：短回复与结构化测试都通过，展示模型实际回复、耗时和时间。
- **橙色**：模型能返回文字，但结构化测试失败；调整该模型的结构化参数后重试。
- **红色**：连接、鉴权、模型访问、正文或响应格式失败，结果框显示具体原因。
- **未验证**：未测试，或 URL、密钥、模型参数已经变化；旧结果不能证明当前配置可用。

模型列表接口不可用不会阻止手填模型的回复测试。HTTP 200 但正文为空、仅有思考、输出截断、拒绝、无效 JSON 都不会显示完全通过。结果只证明本次短请求成功，长上下文和角色业务能力仍需实际使用验证。

测试无自动重试，无聊天兜底，不携带角色资料，也不写入聊天、记忆或角色状态。每项最多等待 120 秒，测试输出上限为模型配置上限与 4096 token 的较小值；不会为通过测试而暗中关闭思考。预算不足会明确报告，可取消等待。保存或切换模型不会自动测试。

## 密钥与备份恢复

页面凭据使用 AES-256-GCM 加密存入数据库，主密钥位于 `${DATABASE_PATH}.llm-key`。例如数据库为 `data/personasim.sqlite`，对应文件为 `data/personasim.sqlite.llm-key`。单机版首次保存非空 API Key 时创建该文件；联网版个人供应商的 **URL 和 API Key 分别加密**，保存 URL 也需要该密钥。它与书信的 `INSTANCE_SECRET` 相互独立。模型参数和功能选择是普通数据库字段，不代表整个 SQLite 数据库加密。

联网版每个账号的密钥位于服务端 `users/<用户ID>/business.sqlite.llm-key`，URL 密文与 API Key 密文使用不同的绑定标识。服务端代发请求时解密，客户端读取配置只获得 URL、模型与凭据状态，不返回 API Key。联网版备份应使用[双包加密备份与恢复](HOSTED.md#加密备份与恢复检查)：供应商密文位于数据包，账号的 `.llm-key` 文件进入独立密钥包。丢失密钥会同时影响加密地址和凭据的恢复。

以下是单机版备份与恢复方式：

备份格式 v2 包含供应商密文与主密钥指纹，不包含主密钥文件；旧 v1 备份仍可读取。请将 `.llm-key` 单独保管，恢复时显式提供：

```powershell
pnpm selfhost:restore -- --backup <备份目录> --database <新数据库路径> --assets <新资产目录> --llm-key-file <原主密钥路径>
```

恢复会先校验指纹，再将密钥放到目标数据库旁。丢失或不匹配时不会覆盖原密文，也不会阻止读取现有聊天；相关模型凭据会显示不可用。可以恢复原主密钥，或在设置中明确重置供应商凭据后逐一重新填写 API Key。重置保留供应商地址、模型、会话和聊天数据。

仅需恢复聊天数据而没有主密钥时，可在备份/恢复命令显式使用 `--allow-missing-llm-key`；模型凭据恢复范围会单独报告。这不会绕过原有书信 `INSTANCE_SECRET` 校验。

## 连接验证的边界

联网版检测的是服务器到供应商的连接。手机可以访问某个地址，不表示服务端也能访问；个人供应商不支持 `localhost`、内网或 HTTP 地址。模型发现、短回复测试和正式调用统一检查公网 HTTPS 目标，校验全部 DNS 地址并固定连接地址，拒绝重定向、本机、私网、链路和云元数据等特殊目的地，同时限制请求/响应大小与等待时间。

页面连接测试检查短回复与结构化 JSON 两条路径。每个协议应使用该协议对应的供应商配置验证；兼容网关成功不能代表原生 Anthropic 或 Gemini 接口已经验证。自动化测试使用 Fixture 或可控 HTTP 响应，不能代替真实供应商的账号权限与联网验证。

供应商结果由服务端解析、保存并通过既有业务结果与事件机制提供给客户端，不是上游 token 流的原样透传。网页与安卓读取相同的持久化结果。

实际模型回复、用量、延迟与测试报告保存在本地忽略目录，不随技术指南发布。
