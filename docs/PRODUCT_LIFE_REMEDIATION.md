## 执行规则

每批先明确影响范围，再修改和运行必要回归，审阅 diff 后独立提交。共享模块变更应检验原有正向能力，不能用“全部不记”消除误报。无需迁移的批次不改变持久化契约；涉及旧数据的处理必须可验证、幂等，保留来源与取代链。

离线回归用于复现已定位问题和检查产品路径。模型的自然性、主体连续性、场景覆盖与 README 的双方生活目标仍需逐条审阅新的真实对话；修复后不能把旧的失败实测重新标为通过，也不能把 fixture 成功当成真实模型验收结果。
