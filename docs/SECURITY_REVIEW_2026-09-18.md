# Dearvale 托管网页安全检查（2026-09-18）

本轮保留“打开网址进入登录页”的流程，审查并加固仓库内的 hosted 服务。没有修改真实服务数据库、读取供应商密钥、配置域名或 Sakura 控制台，也没有重启正在运行的服务。以下结果说明代码与本地隔离测试，不能代替最终域名的公网验收。

## 已完成的修复

| -------------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |

- Web 生产构建通过；仍有现有的大 chunk 提示。

- 认证与 HTTP 相关 52 项、SSE 新增 3 项、出站与模型网关相关 146 项验证通过，包含错误入口凭据、旧会话、编码路径、连接释放、私网地址、诊断分页和并发额度。

## 域名和 Sakura 上线时的配置

带端口的 HTTPS 地址可以安全使用。端口号是公开连接信息；不显示端口的 HTTPS 仍使用默认 443。优先保证最终域名的有效证书、仅映射用户服务、管理员留在本机、域名及 Sakura 账号保护、邀请完成后关闭注册和加密备份恢复。

详细步骤与限制见 [HOSTED.md](./HOSTED.md)。应用限流不等于上游抗 DDoS；当前检查也未验证真实节点是否正确转发 Host、证书是否自动续期、可信代理是否正确传递用户 IP，以及真实外网下的 SSE 与长请求。
