# Dearvale 首次 API 配置引导

实现方向：**B · 暖白魔法手册**。主视觉以已确认的 key-concept.png 为准，其余四张 concept 图记录连接服务、选模型、成功页及手机单页方向。纸张和水彩插画为独立素材，所有正文、表单、按钮、校验和进度均为真实组件。

## 页面与视觉

- 暖白背景 #fbfaf6、深绿正文 #18392f、鼠尾草绿按钮 #55775d，沿用项目字体与植物装饰。
- 桌面稳定双页底座，左页法杖／小魔法书／雏菊，右页填写区域；完成时法杖只闪烁一次。
- 900px 及以下改为单页，独立裁切动画区域。表单随内容增高，长模型名与 URL 自动换行；新页聚焦标题，不自动打开输入键盘。
- 有真实可用配置时增加已有配置选择器；该状态压缩字段间距，以保证新建表单仍完整落在书页内。普通首次配置保持参考图的疏朗布局。
- 生成图中的占位文案、锁图标与控件由可访问的真实 UI 替代；手机页为可滚动内容，展开帮助和错误信息不会被截断。

## 分流和配置

WelcomeEntryPage 每次挂载先重新请求 catalog，不在查询完成前挂载普通 WelcomePage。只有全局默认 provider/model 均真实存在、不是 fixture，且凭据状态为 ready，才直接进入 welcome；支持环境配置和免密服务。查询失败可重试；不可读凭据提供设置页修复入口，不重置原数据。

引导为连接服务 → 密钥 → 模型 → 点亮法杖 → 完成。已有配置跳过地址／密钥，不修改其现有模型和高级参数。普通 welcome 的创建、导入、草稿和聊天逻辑保持原组件。向导固定自己的入口状态，缓存更新不会卸载完成页；由“进入 Dearvale”显式退出。

## 动画契约

useBookTurn 持有 step、target、direction 和 idle / turning / revealing 状态。前进 0° → -180°，后退 -180° → 0°。720ms 旋转由纸页本身 animationend 提交目标，之后才挂载新页表单、更新进度，并用 160ms 显现。显现完成再解锁并聚焦标题。

翻页时旧表单随当前纸页运动；背面及下层为无表单纸张。只有一份表单 DOM，turning / revealing 期间 inert。开始翻页关闭明文密钥、清除输入焦点并固定叶片尺寸。双击被同步状态锁拦截。1040ms 旋转和 260ms 显现兜底分别只触发一次，状态提交、减少动态效果切换与卸载会清理计时器。prefers-reduced-motion 时即时切页且禁用微光。

## 保存与凭据

controller 独立于动画，保存顺序为草稿测试 → 新建 → 设置默认；已有连接为测试已有版本 → 设置默认。只有短回复与结构化输出均成功才保存。PATCH /api/llm/default 可选 expectedRevision 在事务内校验；原调用兼容，不新增迁移。

创建成功立即记录 provider/revision、清除内存 Key；默认设置失败保留测试结果，只重试默认设置。无法确认创建结果时刷新 catalog，由用户选择找到的配置；明确读到空结果后才可确认重新新建。字段修改／取消递增请求序列并中止旧测试／发现，忽略迟到响应。保存中禁止重复提交，并保护正在进行的保存链。

API Key 只在表单内存和现有服务器加密存储内，不写浏览器持久化存储、URL 或日志。页面卸载清除内存 Key，已有密钥不回显。错误会屏蔽当前草稿 Key。

## 维护验证

自动化检查覆盖 controller 状态、Web API、Welcome 分流、服务与 HTTP 集成，以及入口、查询失败、凭据修复、免密服务、手填模型、保存重试、取消/迟到、双击、反向翻页、减少动态效果、离页清理和手机长文本。设备软键盘行为需在目标设备另行验证。

截图、日志和验收报告保存在本地忽略目录。模型网络交互的 Fixture 与 route mock 用于验证工程行为，不能代表真实云模型连接和生成质量。

素材文件、生成提示及修正过程见 asset-manifest.json。首次输出将透明棋盘格画进 RGB，后经 image_gen 修正为干净实底图，使用 multiply 与暖白纸张融合；未把透明预览棋盘格当作正式素材。
