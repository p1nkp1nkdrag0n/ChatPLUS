# 角色问答创建流程与交互规范

## 已实现的流程

Welcome 从服务端读取已发布的用户角色，决定显示「描述你梦中的他/她」或「继续聊天」。未完成的问答和未确认小传可恢复；服务器读取失败提供重试，离线暂停不按空库处理。导入后发布的角色也启用聊天。最后一个角色归档后恢复创建邀请。

服务器启动不再播种系统示例，旧 SEED_DEMO 配置也不启用播种。公开的示例创建接口返回 410。033 迁移只归档来源或示例注册记录明确识别的角色，保留角色和会话数据，不按角色姓名识别。

`/create` 使用独立书桌场景，按固定顺序呈现十二题。性别、姓名、文字年龄、世界、身份和性格必答；其余可略过。主问题完成后至多生成两个可选追问。浏览器存储保留原文、题号、追问缓存、请求标识和服务器草稿版本。修改答案会使对应旧追问失效。

编译首次建立草稿，后续修改原位更新同一未发布草稿。服务端恢复明确的作者设定，保存版本化访谈来源。预览由可追溯事实组成，小传本身不会作为新增事实写回角色。性别和文字年龄兼容旧角色，并进入编辑器和聊天上下文。

`/characters/:id/preview` 可刷新恢复。发布成功后才更新当前角色并进入聊天。冲突重新读取当前版本，必须确认的模型设定逐项处理。详细编辑或审核已经改变了访谈生成版本时，继续提供详细编辑入口，避免重新编译旧访谈覆盖这些修改。

## 阅读与维护检查

问题、答案、小传和操作控件使用真实 DOM；插画只提供场景与道具。羽毛笔动作应尊重减少动态效果设置，切题和快速重复操作由同步状态锁保护。小传使用独立阅读层，长正文和审核内容必须可滚动、可聚焦，手机布局随安全区域和视口变化。

维护时检查十二题与追问、浏览器草稿恢复、编译幂等、版本冲突、发布、Welcome 角色分流和旧角色兼容。浏览器回归应覆盖长文本、中文 IME、减少动态效果、窄屏、离线失败和恢复。模型相关 Fixture 测试验证流程边界，内容质量需独立评审；截图、日志及报告保留在本地忽略目录。
