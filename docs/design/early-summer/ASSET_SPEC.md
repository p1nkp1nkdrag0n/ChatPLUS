# 独立艺术资产制作与拆解

## 1. 本包有什么，没有什么

`references/` 保存上轮三张原始概念总览，只确认风格。`assets.manifest.json` 是分层生产清单，所有生产项初始为 planned，actualPath/sha256 为空。
本包没有声称已经生成独立天空、云、水贴图或书页模型。技术分镜的框线也不是可上线美术。

先制作每章独立、完整、可读的桌面和手机概念，沿着已认可方向，不重新发明风格。总览里的肖像、猫、图片聊天、附件控件、英文标语、错误文案不属于需求；不得照抄。

## 2. 同一世界的制作规范

清透蓝天、白云、新叶绿、鲜花，明亮左上日光；手绘纹理结合有层次的体积。远山克制空气透视，海水有深浅。无暗黑森林、浓雾、焦黄滤镜、塑料质感或低幼造型。
纸张柔和纸白、低对比纤维；复古来自装订、页叠与不规则边缘，不烧边、不污渍。羽毛笔不是魔法道具；鲜花小量点缀，不贴满文字。
无人物肖像、立绘、背影、剪影、人偶、动物吉祥物。UI 标题、按钮、长正文不烘焙进资产。自然场景是品牌容器，不宣称所有角色真的居住在森林里。

## 3. 每件资产的文件包

master 为透明 PNG 或可编辑源，背景不强求透明；runtime 按需求导出 WebP/AVIF 或 glTF+纹理。不要将每张 master 原尺寸下载给手机。
元数据包括：ID、scene、parent、z、pivot、desktop/mobile 构图、透明安全边、最大运动范围、遮挡关系、静态状态、制作者/生成来源与使用权记录。生成后写实际文件尺寸、字节和 SHA-256，再审核。
建议场景 master：桌面 2560×1600，手机 1170×2532。手机重新安排标题安全区，不用桌面两侧裁切充数。小物件按实际显示比例输出，不都做 4K。
透明资产留出约 12% 运动余量。会移开的物体必须完整；背后区域、信纸背面、封口内面、页叠边缘补画。只裁总览矩形会露洞，不能作为生产方法。

## 4. 场景拆解

S01：天空完整背板、远/近云、山、中林、近枝、草坡、重点花茎/花头。远景叶簇分组；重点花允许更精细结构。山稳定，枝从基部弯。
S02：森林后板、河岸、水面、前石、树冠、树影。flow map 与 hit mask 是需要验证的技术数据；白水域/黑非水域，石头区排除。纹理显示与点击使用同一 UV。
S03：桌面、书封、页叠、左右页、信封前/后/封口、空白信纸、笔、鲜花。装订和折线确定 pivot，按动作交换正确的前后遮挡。
S04：天空、云、海岸、远海、近岸浪线、前草。海平面不旋转，近岸低强度动。
UI：低对比纸纹、页边、书签、少量植物印记。日常只用这些轻资产，不加载环境全景。

## 5. 可直接交给美术/图像工具的 brief

**通用：** 同一初夏世界，清透、明亮、青春；手绘质感与风格化体积。统一左上光向，无人物或动物主角、无 UI 文案。产出指定独立资产，不是整个网页截图。保持完整轮廓与运动余量，不加整图暖色罩。

**S01：** 补全被树遮挡的天空。远/近云分别透明导出，有横移余量；山不与云合并；近景枝干/叶簇分组且根部固定；重点花茎和花头可衔接，透视一致。标题区域低细节。

**S02：** 岸石不与流动水烘焙为一层。先定河道轮廓与 UV，再出 base/flow-map/hit-mask。工具不能保证正确流向或 mask 时明确由技术人员制作数据，不把一张漂亮水图当命中遮罩。

**S03：** 同一镜头制作分层书封、页叠、左右空白页、信封前/后/封口、空白信纸、羽毛笔。所有会露出的背面完整；纹理不影响 16—18px 中文阅读。鲜花独立，远离主要正文区。

**S04：** 稳定海平线，分开天空、海岸、远海、浪线、前草，统一光向。宽阔来自构图，不加镜头旋转或新故事地标。

## 6. 验收

逐层开关能看见完整物件；最大视差不露洞；植物根部不漂，纸轴不穿帮；水只命中水；阴影方向一致；静止画面完整。检查透明白边、压缩色带、纹理接缝、高 DPI 模糊与文字安全区。
开发占位可用于逻辑测试，但须标注。不得把粗糙 SVG、渐变或大图裁切当完成；有阻塞就记录受阻 asset ID，不伪造 ready。
