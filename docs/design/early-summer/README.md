## 固定决定

官网承担主要艺术投入；首次应用体验轻量；日常主要改善材质、排版与微交互。艺术元素是天空、白云、山林、树木、鲜花、溪流、海洋、复古书页与羽毛笔。整体初夏、清透、青春，非焦黄古董、暗黑森林或低幼卡通。

不制作人物肖像、立绘、3D 人偶、背影或剪影，但保留文字角色设定。主要景物独立可动；远景细碎元素可分组，不要求每片叶子单独建模。不把整张概念图缩放当实现。

四章次序：天空与花坡 / 林间与溪流 / 书页与羽毛笔 / 溪流入海。三个母题：风拂过、水回应、纸展开。
第二章标题固定为：**不只是回答你，也记住你说过的话。**
不新增签到浇水、失联枯萎、关系积分花、人物吉祥物、虚假注册、图片聊天上传等功能。
