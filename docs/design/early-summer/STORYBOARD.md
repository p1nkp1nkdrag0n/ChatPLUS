# 动效分镜 · 风拂过 / 水回应 / 纸展开

本文件是明确的实施设计，数值是初始调试值，不是实测结果。

## 0. 坐标、进度与运动所有权

审阅画幅：1440×1000 桌面、1024×900 窄桌面、390×844 手机，补查 360 宽与 200% 缩放。原点左上，构图坐标用百分比。
每章进度 `p = clamp((scrollY-startY)/(endY-startY),0,1)`；首章 startY=0；其他章 startY=max(0,sectionTop-viewportHeight)；endY=sectionTop+sectionHeight。窗口变化后重测布局。

滚动进度、环境时间、物件点击状态分别管理：外层 scroll transform，中层 ambient transform，内层 interaction transform。不得多个系统覆盖同一 transform。文字/按钮是独立 DOM，不跟随风、水、鼠标倾斜。
正常文流纵向滚动，不拦截 wheel/touch，不强吸附，不要求看完一段动画才能继续。第一版不整页 pin；额外视差是相对文流的微小偏移，不是固定画布假滚动。快滚、反滚、锚点、前后退直接落到当前状态，不补播、不排队。
环境时间只累计可见且允许运动的时间；离屏、hidden 后恢复不跳跃。固定随机种子；测试可锁定时间、p 和风力。

## S01 · 天空与花坡

**构图。** 上部约 45% 为清透天空。标题安全区 x=14%—67%、y=18%—52%；树枝不穿过文字。远山地平约 y=57%；单侧树冠入画；花草在下沿和右下。不使用玻璃卡片盖住整片风景。

标题：让相遇，慢慢成为故事。
说明：与拥有自己生活脉络的虚构角色对话，让记忆、书信与共同经历逐渐积累。
按钮：开始使用 / 了解更多。首帧已经可以操作，不等云散或花开。

**后到前。** S01-SKY → CLOUD-FAR → CLOUD-NEAR → MOUNTAIN → FOREST → BRANCH → MEADOW → FLOWER-STEM → FLOWER-HEAD。sky 与地面在遮挡区补全。

| 帧 | p | 景物 | 文字/操作 |
| --- | --- | --- | --- |
| S01-A | 0 | 完整首帧，慢云与极轻微风 | 标题、说明、CTA 都已可用 |
| S01-B | .25 | 近景额外上移 12px，山约 1.5px | 正常随文流移动，不随鼠标 |
| S01-C | .50 | 近景 24px，树冠 12px，山 3px | 不分字消失、不截断阅读 |

最大额外视差：近景 48px、枝冠 24px、中林 12px、山 6px。手机最多 12px；reduced/still 为 0。

**I01 拂花。** 鼠标经过近景命中区域，花茎从基部弯，花头约晚 60ms 跟随；影响半径 110 CSS px，最大额外 4°，600ms 回稳，扰动冷却 120ms。微风 0.5°—1.2°、周期 6—10 秒，相位不同、总体风向一致。高频鼠标不积累成风暴；不喷粒子、不全屏追随、不磁吸按钮。触屏不注册持续 pointermove、不 preventDefault，不损失任何必要内容。

**T12 树冠接续。** 两章保持光向、植被与空间关系，在边界留 10%—15% 安全接续区域；遮罩只处理接缝，不给全图套色。禁止全屏叶片幕布、黑屏、闪白和巨大镜头推进。

## S02 · 林间与溪流

**构图。** 左侧约 42% 稳定阅读区，右下独立河道、岸与石；初夏日光而非暗森林。对话示例用正常 DOM，不漂在河面，不烘焙成图片。
标题固定：**不只是回答你，也记住你说过的话。**
说明：记住有来历的细节，让下一次交流不必从头开始。

**后到前。** S02-FOREST-BACK → BANK → WATER → ROCKS → CANOPY → SHADOW。FLOW-MAP/HIT-MASK 是功能数据，不直接显示。

| 帧 | p | 景物 | 示例 |

| S02-A | 0 | 上章植被色调与光线延续 | 无 JS 也有完整 DOM 内容 |
| S02-B | .25 | 溪流进入，纹理沿实际河道运动 | 示例到位，额外位移 ≤12px |

**I02 触水。** 仅命中水域 mask 才出涟漪。石、岸、UI 不触发；寿命 900ms，半径最大 64px，并发 ≤3，冷却 200ms。水面显示与命中共用 UV；缩放裁切后仍正确。手机 tap 不抢滑动，装饰不调用 API、不承载必须发现的信息。reduced/still 不产生水纹。

**对话示例。** 明示“对话示例”，使用 `copy.zh-CN.json` 的合成内容。展开不模拟真实用户会话；不加头像生成、图片上传、虚构工具。初始“此前提到”的背景只属于示例，不宣称每次回复都准确记住全部历史。

**T23 同一束光。** 树林细节逐渐减少，相同方向的树影落上纸面；不是森林硬变成一本书，不新增凭空飞来的对象。

## S03 · 书页与羽毛笔

**构图。** 左文案、右物件；一本书、一封信、一支羽毛笔、一小段鲜花。纸白低对比纤维，旧感来自页叠和装订，不烧边、不焦黄。光向与前章一致。阅读文字独立 DOM。
标题：有些话，值得慢慢抵达。
说明：把重要的话写成信，让有来历的经历留下可以重读的痕迹。
按钮：查看书信演示。

**后到前。** S03-TABLE → BOOK-COVER → BOOK-BLOCK → PAGE-LEFT/PAGE-RIGHT → LETTER → ENVELOPE-BACK/FRONT/FLAP → QUILL → SPRIG → SHADOW。
纸页轴在装订线，信封轴在封口折线，遮挡随动作正确变化。背面与被遮挡面必须画完整。

| 帧 | p | 物件 | 阅读 |
| --- | --- | --- | --- |
| S03-A | 0 | 树影接纸，书以约 7° 展示 | 文字不变形 |
| S03-B | .25 | 书约 4°，笔随父层进入 | CTA 已可用 |
| S03-C | .50 | 书约 1°，物件稳定 | 可随时点击演示 |
| S03-D | .75 | 不因滚动自动开信 | 点击状态独立，反滚不重置 |
| S03-E | 1 | 纸白与下一章天空衔接 | 正常离屏，资源暂停 |

**I03 展信。** `closed → lifting → unfolding → readable`：0—120ms 上移 3px；120—300ms 沿折线开封口；300—600ms 信纸展开到稳定阅读区。可跳过；reduced/still 直接 readable。再次点击不重复演出；键盘操作与点击等价，阅读标题获得合理焦点，不锁滚动。
官网使用明确标记的固定示例，不调用真实 `/open`。真实应用仍使用既有安全读取路径；授权后才能显示正文，失败时显示错误，不播放成功状态。

**羽毛笔。** 默认静止。可选点击后写一句很短的装饰笔迹，主标题和说明已存在；不替代系统光标，不让用户等它写完。首版优先展信，不为“所有东西都动”强加写字演出。

**T34 从手边到远方。** 书页随正常文流离开，纸白留白与天空在边界接续，再露出海面；依靠明度与空间尺度，不用书变海浪。
