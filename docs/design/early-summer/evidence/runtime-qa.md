# 本轮官网资源与运行测量

日期：2026-09-08 08:20:14 UTC；页面：隔离 fixture 的 `http://127.0.0.1:43179/about`。Windows 上的 Headless Chromium 151.0.7922.34，Vite 开发服务器；1440×1000 与 390×844 CSS px，DPR 都为 1。先完成其他浏览器测试，再顺序采样，避免本轮 E2E 与帧采样争用。

原始数据为 [runtime-measurements.json](runtime-measurements.json)，包含两个画幅各 601 个 rAF 间隔、ResourceTiming、图像尺寸与全部 120 条场景采样。工作树测量包含当时尚未提交的实现，不将记录中的 git HEAD 当作所有测量源码均已提交的证明。

## 首轮发现与修复验证

首轮保持原生 `loading=lazy` 时，滚动前已经下载全部 15 个美术资源：桌面 3,518,232 B、手机 1,294,928 B，均超过首屏目标。原始数据保留在本机 `tmp/early-summer-runtime-before-loading-gate.json`。

实现随后改为在各章实际进入视口时挂载 src/srcSet，保留 img 节点与 load 监听，离开章节后保留已加载内容。第二轮实测首屏变为上表的 7 个资源。E2E 另检查首屏不请求 S02–S04，以及逐章进入后真实下载与解码；没有将“素材清单里只数 S01”替代真实网络统计。

## 状态与画面

两个画幅各遍历 4 章 × 5 个目标进度（0/.25/.5/.75/1）× 3 种动效偏好（auto/reduced/still），共 120 条采样，全部 `scrollWidth ≤ innerWidth+1`。末章每种模式的两个较晚目标超出文档最大滚动范围，共 12 条标记 clamped；这些目标没有被声称为实际到达。离屏或静态场景保留的 CSS progress 不等于新的活动进度，原始记录同时保存 active、travel、目标和实际 scrollY。

另以 720×500 CSS px / DPR 2 检查相当于 1440 像素桌面 200% 时的横向重排；scrollWidth=innerWidth=720，无横向溢出。此方法不是原生浏览器缩放，也没有模拟 pinch zoom。[查看重排截图](runtime-200-percent-reflow.png)。

完整单章主视觉与两画幅 welcome 已保存在本 evidence 目录，文件索引和主参考对照见 [visual-review.md](visual-review.md)。完整单章截图在图像实际加载后保存，welcome 等待 220ms 有限入场动画结束；已人工 view 检查全部四章与稳定 welcome，标题、操作和装饰边缘可见。手机海岸标题按“故事不必 / 一开始就完整。”完整词组换行。三张网格仅用于补充动效模式抽样，不能替代这些主视觉截图：

## 复跑与边界

```powershell
node scripts/measure-early-summer.mjs --url http://127.0.0.1:43179 --output tmp/early-summer-runtime-final
```

本轮命令退出码 0。脚本保留轻量原始间隔与网络记录，没有制造大体积 trace。rAF 是回调节奏，不能证明 GPU 每帧实际呈现；上述 LCP/CLS 是本机单次导航实验，不是线上分位数。点击至 DOM/下一 rAF 是交互延迟观测，不是 INP。Vite 开发模块总字节不用于评价生产 JS gzip 预算。没有执行低端真机、OS 最小化调度、实际旋转/pinch 或真实浏览器 200% zoom；这些项目仍不得自动视为通过。
