# 连续对话的回复形式诊断

这个离线工具检查同一段按实际顺序记录的对话，帮助定位篇幅、气泡数量和开头反复相似的情况。它不调用模型、不改变角色策略，也不把“更长”“更多分段”或“每轮都不同”作为质量目标。

将每个逻辑回合的最终可见回复放入 `turns`，按发生顺序排列，每个 `turnId` 唯一。不要混入重试候选、单个气泡、其他会话或独立场景重采样。`assistantChunks` 是实际交付的气泡正文数组；没有记录就省略，工具会报告未知，不能从换行猜测气泡。

```json
{
  "turns": [
    {
      "turnId": "t1",
      "userText": "我把桌上的花换成橘子了。",
      "assistantText": "能看还能吃，这束花很实在。",
      "assistantChunks": ["能看还能吃，这束花很实在。"]
    },
    {
      "turnId": "t2",
      "userText": "结果刚摆好就少了两个。",
      "assistantText": "花期也太短了。\n下次得先留一张全家福。",
      "assistantChunks": ["花期也太短了。", "下次得先留一张全家福。"]
    }
  ]
}
```

上面是人工编写的格式示例，不是模型效果证据。真实回归应使用更长的连续对话，包含闲聊、具体问题、倾听、话题切换和明确要求详细解释的回合；评审同时读取用户当前请求，确认表达变化服务于语义。主生成提示是否真的收到之前的回复，需要另查请求记录，不能从本工具的输入顺序推断。

运行方法（输出文件须不存在，避免覆盖原始证据）：

```powershell
pnpm exec tsx apps/server/src/scripts/conversation-quality-report.ts corpus.json form-report.json
```

`responseForm` 同时报告：

- 可见长度：NFC 规范化后去空白的字素数量，包含标点；最小值、最大值、均值、中位数、样本标准差及不同观测值。
- 句子片段数、空行分隔的段落数与实际气泡数的分布。句子由 `Intl.Segmenter` 分段，只是结构近似。
- 开头的重复：第一个标点前的短语，最多取 12 个字素；保留回合编号、频次、占比和最长连续出现次数。它不能识别所有近义套句。
- 形式的重复：`句子数/段落数/气泡数`，例如 `2s/1p/2c`。缺失气泡记为 `unknown`，不冒充单气泡。
- 原有词面开头检查和需要人工判断的追问、意图重猜、过度分析项目。没有人工评审时这些质量计数保持 `null`。

既要查看长度分布，也要查看形式和开头的聚集。几条都很短且结构有效，不能单独证明自然；形式高度重复也只是复核线索，安静陪伴或作者指定的固定口头禅可能合理。不同角色、不同场景的统计应分别保留，避免把混合后的离散度误判成同一角色在连续聊天中已有变化。
