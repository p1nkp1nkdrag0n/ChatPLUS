# 独立角色生成质量盲审：简短判据草案

只读取匿名卡中的作者原始输入、允许补全的范围、生成结果与必要的生成状态；不读取模型、实验分组、原始结果路径或映射。先列明作者硬事实与性格要求，再评生成结果。文字长短、字段齐全与否，不能代替内容质量。

1. **作者事实与性格保留**：身份、关系、世界背景、关键经历、边界与作者明确的性格是否保留且内部一致；关注遗漏、改写、反转与被通用“温柔陪伴”稀释。保留要体现在具体判断、行为倾向、表达及例外中，复述几个形容词不足以证明成功。
2. **设定扩写是否越权**：区分作者事实、授权的创作补全、合理的低约束细节与擅自确立的新核心设定。新增关系身份、重大经历、创伤动机、道德立场或世界规则，须核对授权范围；开放创作本身不应被一概判成幻觉。无法知道授权范围时明确无法判断，不推定禁止补全。
3. **生成是否模板化**：看新增内容是否由这个角色的作者输入具体推导，还是换名即可复用的履历、目标、习惯、安慰腔和关系进展。共同 JSON 结构不算模板化；反复套用同一心理解释、冲突解决方式和无关细节才是内容证据。
4. **三种性格是否可区分**：在共同事实和相同情境下，能否凭观察重点、表达力度、判断方式、玩笑边界与回应选择区分三者，而非只靠标签、字数或感叹号。温和观察不应自动心理咨询，沉静直接不应等同冷漠，明快外向也不应在严肃场景强行打趣；以各卡作者原文为最终依据。

逐项记为“保留充分 / 部分弱化 / 明确违背 / 无法判断”，附一条具体证据；模板化与性格区分须结合整组三种角色，不从单卡推断跨卡重复。成对比较保留 tie 与 unscorable，写明置信度，不编造自然度分数；格式失败单独记录，不伪装成内容质量结论。
