# 开源项目调研建议的第一批实现

来源：用户引用的 ChatGPT 会话《调研对比开源项目》（2026-09-09）；调研所审阅的 ChatPLUS 提交为 `3bf43bc`，与本次开始时的工作区 HEAD 一致。本轮不重新为其他开源项目排名，而是在当前代码上验证调研发现、修复确定的问题，并补充可归因的实验入口。

## 实施范围

| 建议                     | 本轮落点                                                                                              | 验证含义                                                                                         |
| ------------------------ | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 召回与记忆使用共享相关性 | `memory-recall.ts` 生成绑定查询、记忆内容、来源证据和评分原因的 `relevance`；`memory-use.ts` 复用结果 | 已通过召回的证据不再因第二次只检查词面而失去提及资格；提及预算、话题范围、重复和撤回过滤继续适用 |
| 混合召回的机制实验       | 可选 `semanticSignals` 只对已有候选评分；新增 `test:memory-relevance:fixture`                         | 以标注分数检验检索与提及门控的 2×2 关系，不代表已经部署 embedding 服务或验证其质量               |
| 细分表达控制             | 保留旧五字段组合消融，新增长度、气泡数和投递指导三个独立模式                                          | 每个实验模式只移除声明字段，预算分配完成后再投影；节省的空间不会补进新证据                       |
| 冻结实际运行配置         | 回复实验 manifest 区分部署配置与明确覆盖后的评测配置                                                  | 避免将专门构造的评测配置误当成默认产品配置                                                       |
| 中文与结构化文本预算     | 统一使用带版本号的 Unicode 估算器，预算准入、裁剪与诊断使用同一口径                                   | 修复按 UTF-16 字符长度除以 4 对中文/JSON 过于乐观的估算；仍需用真实 provider usage 校准          |

共享相关性改善的是已有记忆使用流程。日常产品的 `COMPANION_CONTEXT_MODE`、`PERSONA_RUNTIME_MODE` 和各服务默认开关不因本次实验自动切换；只有原有上下文流程执行记忆使用门控时，才适用新的共享判定。主动消息仍按现有产品配置关闭。

另已修复普通记忆的第 30 天召回断点：直接询问“还记得／回忆一下／do you remember”时，关键词候选池和纯召回规则允许查询 `aging` 历史记录。否定、引文、转述和假设中的回忆措辞不授予这个权限；查询扩展也不能授予。日常闲聊和当前事实查询仍按现有活跃记忆规则处理；不会将历史记录重新设为 active，也不会恢复 archived、过期、被取代或撤回的事实。真实 SQLite 的第 29／31 天生命周期、服务重建和 replay 测试覆盖普通与分层召回路径。

最终共享相关性版本为 `memory_relevance_v2`，同时绑定证据来源类型、原文和上下文摘要；即使有原文，摘要发生变化也会使旧相关性失效。v1 元数据仍可读取，但需重新召回才能获得当前共享使用资格；完全没有相关性元数据的旧记录仍走兼容的词面门控，不需要数据库迁移。

用户授权的 GLM 实测进一步发现：准备步骤、展开比较、代拟文本等明确请求被旧解析器漏判。v2 以请求动作和交付物识别这些帮助需求，保留否定、转述、先听后帮、将来请求与将来使用的区别。最终 `clause_requests_v3` 进一步产生 `structuredTaskRequested`，将当前明确要求的准备顺序、步骤或清单交付映射到至少 `complex` 的回复复杂度；明确要求简短仍优先，延后帮助、倾听与短代拟请求不会因此统一变长。读取旧记录时兼容 v1、v2 和缺失版本。各阶段的真实测试独立保存，见[GLM 真实验证报告](../reports/2026-09-10-research-optimization-glm-validation.md)。

真实调用还定位了一种明确的输出协议错误：顺序气泡有后续新内容，但规范 `text` 精确等于首个气泡。最终契约会标记 `INCOMPLETE_CANONICAL_REPLY_TEXT`，通过已有的一次 `repair_chat_turn` 修复机会补全正文；修复仍失败时使用既有兜底，不直接拼接气泡。完整正文配上无关错误气泡仍保留原有降级行为；这项窄规则不能检测全部未完成任务或所有正文/气泡不一致。

## 记忆召回 × 提及门控

```powershell
pnpm test:memory-relevance:fixture --output tmp/memory-relevance-NEW
```

输出目录必须是仓库内被 Git 忽略的新目录。已有实验不会被覆盖。命令不读取模型密钥、不调用模型或 embedding API，不使用用户数据库。

| 实验组 | 候选评分                             | 使用门控   |
| ------ | ------------------------------------ | ---------- |
| R0U0   | 当前词面召回                         | 旧词面门控 |
| R0U1   | 当前词面召回                         | 共享相关性 |
| R1U0   | 词面 + 绑定到证据的 fixture 语义分数 | 旧词面门控 |
| R1U1   | 词面 + 绑定到证据的 fixture 语义分数 | 共享相关性 |

R0/R1 共用本轮实现中的来源、标识符、生命周期、命名空间和时间过滤，不是历史提交回放。语义分数是显式合成输入，不能凭它扩大候选数据库范围、制造来源，或将相似但不同的编号视为同一个实体。未来接入真实 embedding 时，仍需实现并验证索引增量更新、候选发现、部分索引覆盖、查询绑定和模型/索引版本，不能把本命令的结果当成这些工作的验收。

12 个场景 × 4 组，共 48 个确定性探针，覆盖中英文无词面重合的改写、未建立语义信号的新记忆、相近编号、过期、被取代事实、命名空间、无证据记录、撤回、近期重复、倾听偏好和无关高重要性记忆。标注区分：应召回、允许显式提及、不得召回、不得使用。禁止项和意外提及使 CLI 失败；召回与提及遗漏分开报告，以定位损失来自哪一层。

产物包括：

- `manifest.json`：固定时钟、阈值、组别、完整合成场景、语义分数来源、Git 提交、相关源文件 SHA-256 和场景 SHA-256。
- `results.json`：每个场景/组的选中记忆与证据、共享相关性绑定、评分、提及权限、遗漏原因和约束检查。
- `comparison.md`：四组召回遗漏、提及遗漏、意外提及、禁止召回和禁止使用分别计数。

不将这些合成探针当作独立用户会话样本，不计算自然感得分、统计显著性或真实模型改进百分比。

## 上下文预算与展示

`unicode-heuristic-v1` 是模型无关的规划估计，不是 tokenizer，也不是所有模型的严格上界。诊断保留估算方法及估算值，provider 返回的真实 usage 单独保留。预算变化可能使中文或 JSON 较多的上下文更早触发压缩；应通过 trace 检查实际准入的段落与证据，而不能继续拿旧估算数与新估算数直接比较。

证据、近期原文和自传按完整记录压缩，当前用户消息的结构完整性继续受保护。实际 usage 可能包含消息封装、输出 schema 等传输内容，不能要求其与正文估算相等。

调研提到的“气泡数量影响历史轮数”在当前项目未出现：`DatabaseStore.insertMessage` 保存整条回复，气泡记录在元数据；聊天历史选择读取整条 `content`，前端 `resolveMessageDelivery` 只决定如何展示。因此本轮不新增冗余的语义回合数据库字段。后续进行展示体验实验时，应冻结相同回复文字与消息 ID。

## 后续实验边界

经作者审核的话语样本、人物区分度盲评、低复杂度完整系统基线、上下文注入位置/持续、主动话题价值排序、角色公开简介与社会关系仍是后续独立实验。当前没有足够实测证据支持同时启用这些机制或改变产品人格。应先用固定前缀回放观察本轮变量，再开展各自独立写入的长期会话验证。
