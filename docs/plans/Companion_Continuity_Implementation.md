# 长期角色陪伴：实施记录

基线：`dc51b5cba3dee574c86ba4bd58337c93b2d8b555`，2026-09-06。分支：`codex/companion-continuity`。

本轮依据《ChatPLUS_Development_Implementation_Guide.md》和“审视角色对话设计”三轮讨论实施。参考材料描述的是建议；下列边界是核查代码后采用的实现决策。原计划书保留原文，实施结果和偏差在本文件更新。

## 验收目标

普通相处能形成连续性：完整而有来源的记忆、可纠正的理解、无需强制建议的日常聊天、没有预设人生主线也能运行的角色，以及有证据且只影响适用范围的相处方式变化。保留明确委托决定、不可变已发布档案、角色队列、短事务、事件因果链和历史回放。

## 耦合分析与实现顺序

| 工作包       | 必须一起处理的边界                                                   | 验证与提交单位                     |
| ------------ | -------------------------------------------------------------------- | ---------------------------------- |
| 基线         | 固定场景与现有策略，不用模拟测试声称真实自然度已改善                 | 文档和人工事实夹具                 |
| 证据语义     | memory、自传、checkpoint事件卡共同使用保守验证；模型调用留在事务外   | 纯规则与实际持久路径回归           |
| 完整证据预算 | 组装器和最终分段预算均不能截掉否定、条件或半个JSON                   | 独立预算回归                       |
| 纠正传播     | 当前记忆版本与派生对象失效在同一事务；保留原文、历史和已发送快照     | 重启、回滚、跨角色与历史查询       |
| 普通聊天     | 近期原文先于检索；扩写只找候选，原文继续决定事实与授权               | 意图、检索审计、提示词与服务链路   |
| 角色生成     | 表单、共享合同、默认草稿、模型后处理、发布、生活初始化共同允许空目标 | 兼容旧角色与无目标生成发布         |
| 当前人格     | 基线与适应分开；生成、校验、修复使用同一冻结投影                     | revision、来源失效、重试、书信快照 |
| 局部学习     | 观察与权威适应分开；只接受明确来源和限定范围；不得自证               | 幂等、证据栅栏、撤回和新会话       |
| 生活变化     | 生成用相关片段，校验仍用完整快照；旧日历策略保留                     | 无事件不推进、终态目标不复活       |

不在本轮增加外部向量数据库、完整心理图谱、全局traits/values自动改写或复杂社会模拟。导入全文/场景索引及语义候选提供器属于原指南可选后续项，需先有真实失败样例。

## 实施约束

- 独立模块并行开发，共享编排和Git操作统一完成；每批只暂存本批文件，验证后提交并立即推送。
- 追加数据库迁移，在隔离数据库和既有备份/恢复测试中验证；不对日常数据库执行实验或迁移。
- 沿用现有Fixture与provider stub，不发起付费模型调用。工程验证与真实语言体验验收分别报告。
- 新体验策略支持逐步启用；已证实错误的记忆不能随体验开关关闭而重新生效。

## 进度与验证

初始记录：工作区只有用户提供的未跟踪计划书；没有既有源码修改。基线与远端main一致。后续提交将记录实际通过的检查、接口决策和剩余限制。
