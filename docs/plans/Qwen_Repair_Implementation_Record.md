## PR-1：状态归属与持久化入口

完整 T8 的 HTTP 回归先复现 `expected 0 / actual 1` 压力记录。新解析接口保留原动作解析的历史 subject 语义，状态候选另用相对体验者、实际说话者、模态和原始 UTF-16 span。局部省略有边界；认知框架、句间和新话题不能无限继承。后置体验者（事情压着我）和同一主体的压力/清晰度量表仍可表达。

角色压力从最终已保存消息重新解析；仅本人断言、当前来源及回复前运行时状态支持的候选可进入压力投影。本轮模型 state delta 不能反过来授权这轮自述。普通当轮表达保留，缺少持久化依据的候选记录独立 `life.pressure_candidate_rejected`，不改写为用户压力。数值标明 `explicit_self_report / algorithm_initial / algorithm_update`，不将缺省 0.72 声称为测量。

旧有正向角色压力测试现在显式配置独立的高压力/低精力初态；省略主体的用户正例改为明确本人表达，另有 unknown 不写的对照。完整 T8 原文与原始实验保持不变。正向用户压力、支持方向、显式帮助、一次修复和重放均由集成测试分别检验；后续数据失效及全量验证另行提交。

## PR-3 与 PR-4

`advice_load_v2` 区分建议框架否定与活动内部修饰；“不用动脑子的事，比如洗澡或翻杂志”保留两个实例建议。未解析动作保留候选、UTF-16 位置和覆盖状态。`none_now` 下明确的未解析建议进入现有语义检查和一次共享修复预算；不确定框架仅报告复核，转述、角色自述和明确求助分别有正负对照。

当前会话计划增加有限追问意图，以及最近 5 条最终可见回复的开场计数。重复非必要开场至少两次时，只在本轮提示中降低显著性；明确作者口头语受到保护，不写永久偏好或禁词。首次生成和修复共用这份上下文，实质帮助要求区分已知事实、可能解释和待验证信息，允许多种原因并存。

`conversation-quality-metrics.ts` 单独记录词语出现、开场、连续重复和待人工评阅的追问/归因案例；不会把未填写的人工判断算成 0 或 PASS，不改变原 9/3 分母。

## PR-2：创作来源与发布权限

新策略为 `companion_character_v3`。服务端保存具体候选及其原始模型值、目标字段、强度、内容 hash 和来源；模型自报 `origin` 或伪造审计不能授权自己。生成、导入、编辑、恢复、发布共用校验。未获支持的内容隔离为 pending，不通过单纯改软掩盖歧义；作者可以对当前版本的精确候选确认或拒绝。旧发布版本可读且不改写。

独立审查实际复现了两个遗漏，均先加红测再修复：被引用/否定的绝对规则子串不能当作作者要求；实际进入提示的拒绝、安慰等话术也纳入内容 hash 与来源校验。来源要匹配完整源句、施加对象、相邻转述与否认。无法可靠推导时进入待复核，不声称用有限规则完成通用语义蕴含。

版本升级还暴露一个耦合：仅比较 v2 字面值会让 v3 退回旧目标推进策略。统一 `isCompanionCharacterPolicy` 用于时钟、生活线程、模糊生活服务和测试启动器；旧未标记版本仍按原兼容语义读取。

编辑器“约束来源”逐项展示原始候选、模型原值、当前有效值及来源，确认保存新版本。浏览器检查发现页头复用样式会在手机隐藏拒绝按钮，已改独立操作样式。桌面和手机均实际完成候选确认和另一个候选拒绝，检查版本增加、硬约束保留、无框架覆盖层及无页面/控制台错误。
