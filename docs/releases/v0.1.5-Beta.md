- 稳定角色规则、Schema 和历史布局，增加可选前缀诊断；保留实际动态状态与历史可见性信息。

## 已有真实 DeepSeek 证据与边界

[42 轮、模拟 45 天的真实长测报告](../reports/2026-09-06-deepseek-product-life-long-run.md)记录了 99 次完整运行物理请求、62.08% 输入 token 缓存读取率，以及完成后恢复没有新增调用或数据库变化。包含此前中断重跑的两次长测共 149 次请求，按返回 token 与官方价格估算 0.137436280 美元，未与账户实际扣款对账。

真实长测同时确认：周二更正事实没有进入后续回忆 prompt，模型错误回答周三；模拟用户虚构已读未到达回信，角色未纠偏；用户与角色事项发生归属反转；完整因果链仍未覆盖。报告列出代码定位与后续改进方向，不能将真实模型质量问题归因于供应商缓存。
