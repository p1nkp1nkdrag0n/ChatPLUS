# ChatPLUS v0.1.6-Beta

日期：2026-09-08。将 `codex/qwen-three-run-long-validation` 合并到 `main`，保留其相对原 `main` 的全部 104 个分步提交。合并提交为 `4ed0a0979532d9211e21db21a1479c81700f3b05`，两个父提交分别为原 `main` 的 `dc51b5c` 与来源分支的 `19fb1cf`。合并后的文件树与来源分支完全一致。

沿用此前版本约定，以 annotated Git tag `v0.1.6-Beta` 标记发布；私有 workspace 的 `package.json` 版本继续为 `0.1.0`。原版本标签保持原位置。本 Beta 包含工程修复和实验性陪伴能力，真实模型自然度、长期连续性和完整纠错保持尚未通过验收。

本版本的主要改动：

- **角色创建与作者设定。** 允许目标与核心矛盾留空，改进创建、编辑和发布流程；区分作者设定与模型候选约束，编辑器支持核对确切版本中的约束来源，已发布历史保持不变。
- **记忆与事实纠正。** 保留完整来源片段、主体归属、否定和来源版本；让失效来源同步影响派生记忆、自传与事件卡。有限当前事实支持明确纠正、多个事实并存和真实时间变化；修复把正在发生的动作抽取成物品存放位置的问题。
- **有范围的相处偏好。** 新增可选上下文策略和有来源、可撤回的人格实践，覆盖倾听、少追问、平实表达与自然接话。当前明确结束、禁止或独立求助优先，跳过和临时例外不自动变成长久偏好。
- **回复与状态边界。** 初稿和修复共享本轮人格、表达策略及预算实际保留的依据；确认语义冲突才使用一次共享修复预算，不确定风格问题保留诊断。加强压力来源、关怀跟进、用户／角色主体和最终提交前验证。
- **书信依据。** 使用调用局部的不透明引用，由服务端持有参与者身份与到信快照，在生成、执行及加密前校验引用。
- **可复核测试。** 增加可恢复连续性测试、物理请求账本、原始与最终回复分开评阅、自适应两轮纠错协议、合成连续性输入与表达实验执行器。

## 版本边界

真实模型的完整纠错、重启与压缩保持，以及真人连续体验仍需独立验收；提示生成短测不等于正式聊天最终修复与持久化路径的质量结论。结构失败和供应商错误应独立记录，不按成功或零用量处理。

该说明保留版本功能与升级要求。本地实验回复、评分、日志和报告不随源码发布；可复现协议见[双模型测试](../DUAL_MODEL_TESTING.md)与[回复表达评估](../evals/reply-steering/README.md)。
